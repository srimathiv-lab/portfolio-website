# portfolio-website# 🚀 Personal Portfolio Website (Full Stack Project)

A full-stack portfolio web application built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB Atlas**.  
This project allows users to add and display projects dynamically using a backend API and database.

---

## 📌 Project Overview

This is a simple CRUD-based portfolio system where:
- You can add project details (title & description)
- Data is stored in MongoDB Atlas
- Frontend fetches and displays data dynamically
- Backend handles API requests using Express.js

---

## ✨ Features

- ➕ Add new projects
- 📄 View all projects
- 🔗 REST API integration
- 🗄️ MongoDB database storage
- 🎨 Simple responsive UI
- ⚡ Fast Node.js backend

---
